# M9.1 — AROS runner qualification

This gate precedes local AmigaOS qualification.

The GitHub Actions workflow performs:

1. static repository checks;
2. native 68000 Bebbo cross-build using the pinned toolchain image;
3. FS-UAE boot with internal AROS Kickstart and AROS m68k system media;
4. execution of the produced AmBot binary inside the AROS guest;
5. evidence upload including hashes, toolchain identity, guest result and FS-UAE logs.

Passing M9.1 proves that the native binary builds and starts under the automated AROS/FS-UAE environment. Network, ARexx automation, multi-network behavior, CAP/SASL, and AmBNC integration remain for M9.2 local qualification.
