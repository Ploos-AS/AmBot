# M2 — Event Engine

M2 adds a normalized, bounded IRC event layer between the raw IRC session and future bot command/ARexx consumers.

## Implemented

- normalized events for PRIVMSG, NOTICE, JOIN, PART, QUIT, KICK, TOPIC and NICK
- prefix parsing with nickname extraction
- target/text normalization
- fixed-capacity event queue (16 events)
- overflow drop counter instead of unbounded allocation
- shared dispatcher callback API
- session integration after IRC line framing

## Design intent

The event engine is deliberately independent of bot commands and ARexx. M3 can register command consumers against the same normalized event model, while M5 can bridge the same events into ARexx scripts without reparsing raw IRC lines.

## Qualification boundary

`make check` verifies the M2 source invariants. Native Bebbo build and live FS-UAE/AmigaOS runtime behavior remain a separate qualification step.

## Next milestone

M3 adds the bot command layer: command prefix handling, command registry/dispatch, sender/channel context, a basic permission model and built-in HELP, STATUS and VERSION commands.
