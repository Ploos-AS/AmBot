# M3 — Bot Commands

M3 adds the first user-facing bot command layer on top of the normalized M2 event engine.

## Implemented

- `!` command prefix
- static command registry
- command lookup and dispatch from `PRIVMSG` events
- sender, channel/private target and socket context
- USER and ADMIN permission levels
- optional owner nick; owner commands execute with ADMIN permission
- channel replies go to the channel
- private replies go back to the sender
- built-in `!HELP`, `!STATUS` and `!VERSION`
- unknown-command and permission-denied replies

## Runtime contract

```text
AmBot HOST PORT NICK [USER] [PASS] [OWNER]
```

`OWNER` is optional. If supplied, case-insensitive messages from that nick receive ADMIN command context. Later milestones can replace this simple bootstrap policy with persisted configuration.

## Architecture

Commands consume normalized `struct ambot_event` values rather than raw IRC lines. This keeps command handling independent from IRC parsing and gives future ARexx integration the same logical command/event context.

## Qualification boundary

`make check` verifies M3 source invariants statically. Cross-build and live IRC command behavior still require Bebbo/FS-UAE or real AmigaOS qualification.

## Next milestone

M4 adds the live `AMBOT` ARexx message port and maps ARexx commands onto shared internal operations.
