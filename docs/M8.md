# M8 — Modern IRC extensions

M8 adds bounded modern IRC negotiation per network while keeping the AmigaOS 2.04+/68000 baseline.

## CAP

`CAP=ON` enables IRCv3 CAP negotiation. AmBot sends `CAP LS 302`, requests supported capabilities needed by the configured profile, and ends negotiation with `CAP END`.

## SASL

`SASL=PLAIN` enables SASL PLAIN using `SASL_USER` and `SASL_PASS`. The implementation performs the standard `CAP REQ :sasl`, `AUTHENTICATE PLAIN`, base64 payload, and handles success/failure numerics.

Credentials are kept in the bounded per-network configuration structures. SASL PLAIN should only be used over a protected transport.

## TLS strategy

Native TLS is deliberately not embedded in M8. On classic 68000-class machines the preferred model is TLS termination in AmBNC or another trusted local/upstream proxy.

`TLS=UPSTREAM` therefore requires `UPSTREAM=AMBNC`. Invalid combinations are rejected when the network profile is built.

This keeps cryptography and certificate validation outside the constrained Amiga process while preserving encrypted IRC transport beyond the trusted local hop.

## Qualification status

Implementation is present in `main`. Bebbo build, CAP/SASL interoperability, and FS-UAE/AmigaOS runtime qualification remain separate qualification work.
