# M1 — IRC Session

M1 turns the M0 skeleton into a minimal single-session IRC client suitable as the transport layer for later AmBot milestones.

## Implemented

- explicit `bsdsocket.library` open/close lifecycle
- IPv4 hostname resolution using `gethostbyname()`
- TCP connect/disconnect wrapper
- send-all helper for partial socket writes
- bounded IRC line framer with 512-byte line ceiling
- overlong-line discard until the next newline
- PASS/NICK/USER registration sequence
- server PING handling with PONG reply
- reconnect loop with 1, 2, 4, 8, 16 and then 30 second delays
- Ctrl-C exit path

## Runtime contract

```text
AmBot HOST PORT NICK [USER] [PASS]
```

`USER` defaults to `NICK`. `PASS` is omitted unless explicitly supplied.

## Non-goals for M1

M1 intentionally does not yet implement JOIN automation, PRIVMSG command handling, normalized events, ARexx runtime dispatch, CAP, SASL or TLS. Those belong to later milestones.

## Qualification boundary

`make check` verifies the M1 source invariants statically. Native cross-build and live network behavior still need runtime qualification with the Bebbo toolchain and an AmigaOS/FS-UAE environment before M1 is marked runtime-qualified.

## Next milestone

M2 adds a normalized event engine for PRIVMSG, NOTICE, JOIN, PART, QUIT, KICK, TOPIC and NICK, with a bounded queue and one shared dispatcher that future built-ins and ARexx hooks can consume.
