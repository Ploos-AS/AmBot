# M7 — Multiple networks and AmBNC integration

M7 adds bounded multi-network operation while preserving the M6 single-network configuration format.

## Limits

- Maximum simultaneous networks: 4
- Maximum channels per network: 16
- Each network owns its own IRC framer, event queue, command context, hook directory and module directory
- All sockets are serviced by one Amiga task through one `WaitSelect()` call

## Configuration

Multiple networks use sections:

```text
[NETWORK libera]
HOST=irc.libera.chat
PORT=6667
NICK=AmBot
USER=ambot
OWNER=MyNick
CHANNEL=#amiga
HOOK_DIR=REXX:AmBot/Libera
MODULE_DIR=REXX:AmBot/Modules/Libera

[NETWORK local]
HOST=irc.example.net
PORT=6667
NICK=AmBot2
CHANNEL=#bots
```

The old global `HOST`, `PORT`, `NICK`, `CHANNEL`, and related keys remain valid and continue to use the M6 single-network runtime.

## AmBNC upstream

A network can use AmBNC as its transport endpoint:

```text
UPSTREAM=AMBNC
AMBNC_HOST=127.0.0.1
AMBNC_PORT=6697
```

The logical network settings remain attached to the AmBot network profile. AmBot connects to the configured AmBNC listener instead of the direct IRC server and performs the normal IRC registration over that connection. Any AmBNC-side profile or routing is configured in AmBNC itself.

## Runtime behavior

All configured networks connect concurrently. A disconnect on one network does not stop the remaining networks. If every network is offline, AmBot waits five seconds and rebuilds the set. `RELOAD` tears down the current multi-network set, reloads the configuration file and creates the new set.

The existing ARexx control API remains global in M7. Socket-oriented M4 commands operate on the first configured network; network-selectable ARexx commands can be added later without changing the event and configuration model.

## Qualification boundary

M7 implementation is present in `main`, but native cross-build and live FS-UAE/AmigaOS qualification are still required. Qualification should verify concurrent sockets, per-network hooks/modules, AmBNC transport, reload, partial network failure and reconnect behavior.
